# Chained Echoes PL 0.2.0 RC1

Pierwszy publiczny release candidate instalatora Windows x64. To wydanie jest
przeznaczone do smoke testu na czystym kliencie Steam build `21147362`.

## Zakres

- cztery bundle polskich fontów i cumulative katalog Addressables;
- 650 pól dialogowych z rozmów 166–186;
- 1887 pól BGDatabase:
  - `tr_MENU`: 986;
  - `tr_SKILLS_NAME`: 288;
  - `tr_ITEMS_NAME`: 312;
  - `tr_ITEMS_DESCR`: 301.

## Bezpieczeństwo instalatora

- wymaga zamkniętej gry i dokładnie czystego klienta;
- odrzuca wcześniejszy patch, mieszaną instalację i nieznane hashe;
- sprawdza SHA-256 oraz rozmiar siedmiu źródeł i payloadów;
- tworzy pełny backup przed zapisem;
- używa atomowych podmian i instaluje katalog jako ostatni;
- weryfikuje instalację i automatycznie wykonuje rollback po awarii;
- udostępnia osobne opcje Verify oraz Uninstall.

## Walidacja przed publikacją

- build .NET 8: 0 ostrzeżeń, 0 błędów;
- self-testy instalatora: 11/11;
- symulacje install → verify → uninstall → reinstall: zaliczone;
- automatyczny rollback po kontrolowanej awarii: zaliczony;
- pełne testy EchoForge: 106/106;
- BGDatabase: 1887/1887 wartości, round-trip i deterministyczny rebuild zaliczone;
- ZIP: test integralności i wewnętrzne SHA-256 zaliczone;
- EXE: PE32+ Windows x64, self-contained .NET 8, UAC `requireAdministrator`.
